# 综合考核系统 · 军事技能训练 / 学生手册 / 安全知识

一个在线考核系统：从三份 Word 题库中**随机抽题组卷**，**自动判分**、**错题回溯**，
考生用自己设备答题，成绩**自动上传云端**，教师在**教师端看板**上实时汇总全班成绩。

- 学生端：`index.html`
- 教师端：`teacher.html`

## 抽题规则（严格按要求实现）

| 来源题库 | 抽题数 | 其中多选 | 其中单选 |
| --- | --- | --- | --- |
| 安全知识 | 4 题 | 不限 | 不限 |
| 军事技能训练理论 | 23 题 | **6 题** | 17 题 |
| 学生手册 | 13 题 | **4 题** | 9 题 |
| **合计** | **40 题** | 10 题 | 30 题 |

- 每道题自动标注「单选」「多选」标识，并标出来源题库。
- 每题 **2.5 分**，全卷 **100 分**，**60 分及格**。
- 多选题**少选、多选、错选均不得分**（需与标准答案完全一致）。

## 学生端功能

- **考生信息**：考核前必须填写**姓名、班级、学号**，校验通过才能进入答题（学号 4~24 位数字/字母）；
  信息会显示在答题页顶部、结果页与成绩单上，并在本机记住以便下次自动填充。
- **自动判分**：交卷后立即给出最终得分、答对/答错/未作答统计、正确率与用时。
- **成绩自动上传**：交卷判分后自动把成绩写入云端，结果页实时显示上传状态。
  上传失败会在本机暂存并给出「重试上传」按钮，且下次打开页面时自动补传；**不影响得分与成绩单下载**。
- **分题库得分**：按来源题库拆分本次得分（抽题数 / 答对 / 答错 / 得分 + 合计行）。
- **错题回溯**：自动收集全部错题，完整展示题干、所有选项、考生答案与标准答案；
  正确选项绿色高亮，误选项红色标记，「未作答」单独标注。可切换「只看错题 / 全部题目」。
- **成绩单文档**：一键下载 A4 排版的 Word 成绩单（`.doc`），内容含
  ① 考生信息 ② 成绩汇总 ③ 分题库得分 ④ 全 40 题答题明细（逐题给出你的答案与标准答案，正确项/误选项加粗标色）
  ⑤ 签名栏；也可用「打印 / 导出 PDF」生成 PDF。
- **历史考核记录**：每次交卷自动记录到浏览器本地（最多 200 条），首页可查看并**导出汇总表（CSV）**。
- **随机不重复**：每次进入或点击「重新抽题」都会重新随机组卷，同一份试卷内绝不出现重复题目；
  连续两次生成的试卷保证不同。
- **答题卡**：40 题全局一览，已答/未答状态清晰，点击任意题号可快速跳转。
- **键盘操作**：`A`~`H` 或 `1`~`8` 选择选项，`←` `→` 翻页。
- 移动端自适应，桌面端侧边答题卡、移动端自动堆叠。

## 教师端功能（`teacher.html`）

入口在学生端首页右下角的「教师端成绩汇总」。

- **口令门**：需要教师口令才能进入；口令在服务端校验，**不出现在前端代码里**。
  验证通过后本机记住口令，下次自动进入，也可随时「锁定」。
- **统计卡**：参考人数（去重学号）、答卷份数（含重考份数）、平均分、最高分、最低分、及格率、平均用时。
- **成绩明细表**：序号、姓名、班级、学号、得分（含及格/不及格标注）、答对、答错、未答、正确率、用时、交卷时间。
  同一学号多次交卷会标注「重考」，并默认只保留最新一次（可关闭）用于统计与导出。
- **筛选与排序**：按班级下拉筛选、按姓名/学号模糊搜索；支持按交卷时间、得分、班级排序。
- **导出与打印**：一键导出当前筛选范围的成绩册 CSV（含统计行），或打印 / 导出 PDF。
- **删除记录**：单条删除，带二次确认（用于清理测试数据或误交卷）。
- **自动刷新**：看板上每 30 秒自动同步一次，也可手动刷新；页面重新可见时自动同步。

## 成绩汇总架构

```
考生设备                云数据库（托管 PostgreSQL）            教师设备
┌──────────┐          ┌────────────────────────┐          ┌──────────┐
│ index.html│───写入──▶│ exam_records           │◀──口令读取─│teacher.js│
│  交卷判分 │  INSERT  │  · 仅开放 INSERT 策略    │   RPC     │  看板    │
└──────────┘          │  · 无 SELECT 授权        │          └──────────┘
                      └────────────────────────┘
```

- 学生端只被授予 **INSERT** 权限，且写入策略带取值范围校验；**任何人都无法直接读取成绩表**。
- 教师端读取与删除分别走服务端函数 `teacher_exam_records(p_key)` / `teacher_delete_record(p_key, p_id)`，
  两者都是 `SECURITY DEFINER`，在 SQL 内部校验口令；口令错误时读取返回空、删除抛 `42501`。
- 前端只携带 `publicConfig` 中的 `endpoint` / `oauthRelayBaseUrl` / `publishableKey`，
  真实环境 ID 与数据库凭据始终留在服务端。

> ⚠️ 为便于离线部署，`assets/workbuddy-cloud-sdk.js` 是云服务 SDK 的自带副本
> （`@tencent-ai/workbuddy-cloud-sdk@0.1.3-dev.05a12d5`，取自 npm `dev` 通道的 IIFE 构建），
> 因此页面运行时不依赖任何外部 CDN。

## 运行方式

**方式一：线上使用**（推荐，成绩可汇总）

打开已发布的站点，学生直接答题，教师打开 `teacher.html` 查看汇总。
云服务已按发布域名做 Origin 校验，因此**必须通过发布域名访问**，成绩才能写入云端。

**方式二：本地运行**

```bash
python -m http.server 8080
# 浏览器访问 http://localhost:8080
```

本地运行时会因 Origin 不匹配而无法写入云端，但**答题、判分、错题回溯、成绩单下载全部照常可用**，
成绩会暂存在浏览器本地，可导出 CSV。

## 题库更新方式

`assets/banks.js` 由 `tools/build_banks.py` 从原始 docx 题库自动解析生成（仅依赖 Python 标准库）：

```bash
python tools/build_banks.py 军事题库.docx 学生手册题库.docx 安全知识题库.docx
```

脚本内置了针对真实题库排版问题的解析处理，包括：

- 选项与下一题题号粘连（`D.10` + `59.` → `D.1059.`）；
- 小数选项粘连（`D.1.8` + `75.` → `D.1.875.`）；
- 答案标记写在题干中间（`请假（答案：C）以上，…`）；
- 小节标题混入选项末尾（`D.大蒜二、多选题`）；
- 题干跨行、选项同行排列、多选题 A~E 五个选项等。

题目顺序可在首页选择「随机混合」或「按题库分组」。

## 运维备注

- **口令轮换**：口令写在服务端函数的定义中，轮换需改动
  `teacher_key_ok` / `teacher_exam_records` / `teacher_delete_record` 三个函数并重新部署。
- **成绩判分在前端完成**：云端只保存考生上报的结果，不做二次判分；
  写入策略会校验取值范围（分数 0~100、各项计数 0~40、字段非空等）以拦截明显异常的数据。
- 表内数据可用教师端看板逐条删除，或在云服务控制台按需清理。
