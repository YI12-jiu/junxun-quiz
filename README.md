# 综合考核系统 · 自编题 / 军事技能训练 / 学生手册 / 安全知识

一个带**考场管控**的在线考核系统：随机抽题组卷、自动判分、错题回溯，
考生用自己设备答题，成绩**自动上传云端**，教师在**教师端看板**上实时汇总全班成绩；
考核期间检测到违规行为会**立即交卷、上报教师端并在名单中标红**。

- 学生端：`index.html`
- 教师端：`teacher.html`

## 抽题规则（全卷 40 题）

| 来源题库 | 抽题数 | 其中多选 | 其中单选 |
| --- | --- | --- | --- |
| 安全知识 | 4 题 | 题型不限 | 题型不限 |
| 军事技能训练理论 | 23 题 | **6 题** | 17 题 |
| 学生手册 | 13 题 | **4 题** | 9 题 |
| **合计** | **40 题** | 10 + 安全抽到的多选数 | 其余 |

- 每题 **2.5 分**，全卷 **100 分**，**60 分及格**，限时 **60 分钟**。
- 安全知识 4 题**单选/多选不限**（与最初的规则一致），因此每套卷的多选总数在 **10~14** 之间浮动。
- 多选题**少选、多选、错选均不得分**（需与标准答案完全一致）。

## 考场纪律与违规处理

进入考试前需阅读考试须知并勾选同意；点击「开始答题」后自动进入全屏，
并申请麦克风权限用于监测环境声音。

| 违规类型 | 检测方式 | 违规码 |
| --- | --- | --- |
| 退出界面 | `visibilitychange`（切标签页/最小化）+ `blur`（切到其他窗口） | `leave` |
| 截屏 | 捕获 `PrintScreen` 按键；其他截图工具会因夺取焦点而触发 `blur` | `screenshot` |
| 分屏 | 退出全屏（`fullscreenchange`）+ 窗口宽度持续小于屏幕 85% | `split` |
| 复制粘贴 | `copy` / `cut` / `paste` / 右键菜单 / Ctrl+C、V、X，同时禁用文本选中 | `copy` |
| 声音 | 麦克风 + Web Audio 实时测声级（dBFS），超过 **-25 dB** 并持续约 0.5 秒即触发 | `sound` |

**触发后**：立即交卷 → 结果页醒目提示违规类型 → 成绩随记录实时上报云端 →
教师端看板**报警区**列出该条违规、明细表该行**整行标红**并标注违规类型与发生时间。

### 关于管控能力的边界（如实说明）

- **截屏**：可以捕获 `PrintScreen` 按键与因截图工具夺取焦点产生的失焦；但**无法**检测到不改变焦点的系统级截图（浏览器不具备该能力）。
- **分屏**：以「退出全屏」和「窗口宽度占屏幕比例」为准。屏幕宽度小于 1100px 的设备不参与比例判定，避免小屏误报；不支持全屏 API 的浏览器会自动跳过全屏判定。
- **声音**：限值 **25 dB**。浏览器只能测「相对满量程电平」（dBFS），无法测真实声压级
  （dB SPL 需要校准过的麦克风），因此这里的 25 dB 实现为 **-25 dBFS**：
  安静房间约 -55 dBFS，小声交谈约 -40 dBFS，正常说话约 -25 ~ -30 dBFS，数值越大越吵。
  考试页的管控状态条会**实时显示当前声级与限值**，方便学生自查。
  需要考生授权麦克风，**未授权时不监测**，成绩单与教师端会如实标注「未监测」，且不因此判违规。
  阈值与持续时间写在 `assets/app.js` 的 `SOUND_DB_LIMIT` / `SOUND_HOLD`，按考场环境可自行调整。
- **超时不算违规**：倒计时归零属于正常自动交卷，记录标记为「超时交卷」，不标红、不报警。
- 考试开始后有 **1.5 秒缓冲期**，避免全屏切换瞬间的失焦被误判。

## 学生端功能

- **考生信息**：考核前必须填写**姓名、班级、学号**，校验通过才能进入答题（学号 4~24 位数字/字母）。
- **60 分钟倒计时**：顶部实时显示剩余时间；不足 10 分钟出现提醒条，不足 5 分钟转橙、不足 1 分钟转红闪烁；归零自动交卷。
- **自动判分**：交卷后立即给出最终得分、答对/答错/未作答统计、正确率与用时。
- **成绩自动上传**：交卷判分后自动把成绩写入云端，结果页实时显示上传状态。
  上传失败会在本机暂存并给出「重试上传」按钮，且下次打开页面时自动补传；**不影响得分与成绩单下载**。
- **分题库得分**：按来源题库拆分本次得分（抽题数 / 答对 / 答错 / 得分 + 合计行）。
- **错题回溯**：自动收集全部错题，完整展示题干、所有选项、考生答案与标准答案。
- **成绩单文档**：一键下载 A4 排版的 Word 成绩单（`.doc`），含考生信息、成绩汇总、
  考核状态（正常 / 违规 / 超时）与声音监测状态、分题库得分、全 40 题答题明细、签名栏。
- **历史考核记录**：每次交卷自动记录到浏览器本地（最多 200 条），带状态列，可导出汇总表（CSV）。
- **随机不重复**：每次进入或点击「重新抽题」都重新随机组卷，同一份试卷内不会出现重复题目。
- **键盘操作**：按 `A`~`H` 或 `1`~`8` 选择选项，`←` `→` 翻页。

## 教师端功能（`teacher.html`）

入口在学生端首页右下角的「教师端成绩汇总」。

- **口令门**：**每位教师使用各自的口令**登录，口令在服务端校验、**不出现在前端代码里**；
  看板右上角显示当前登录身份（教师一~教师四），验证通过后本机记住，可随时「锁定」切换他人。
  口令被轮换后，已记住的旧口令会在下次同步时被识别并退回登录页，不会静默显示成空表。
- **违规报警区**：有违规时页面顶部出现醒目报警区，按时间倒序列出违规类型、考生与发生时间。
- **统计卡**：参考人数、答卷份数、平均分、最高分、最低分、及格率、**违规记录数**、平均用时。
- **成绩明细表**：序号、姓名、班级、学号、得分、答对、答错、未答、正确率、用时、交卷时间、**状态**、删除。
  违规行**整行标红**并标注违规类型与详情；超时交卷单独标注（不标红）；同一学号多次交卷标注「重考」并默认只保留最新一次。
- **筛选与排序**：按班级筛选、按姓名/学号模糊搜索、**只看违规记录**；按交卷时间、得分、班级排序。
- **导出与打印**：导出当前筛选范围的成绩册 CSV（含状态与违规详情列），或打印 / 导出 PDF。
- **自动刷新**：每 15 秒自动同步一次（有违规报警时更需及时），也可手动刷新。

## 成绩汇总架构

```
考生设备                云数据库（托管 PostgreSQL）            教师设备
┌──────────┐          ┌────────────────────────┐          ┌──────────┐
│ index.html│───写入──▶│ exam_records           │◀──口令读取─│teacher.js│
│  交卷判分 │  INSERT  │  · 仅开放 INSERT 策略    │   RPC     │  看板    │
│ 违规即上报 │  +校验   │  · 无 SELECT 授权        │          └──────────┘
└──────────┘          └────────────────────────┘
```

- 学生端只被授予 **INSERT** 权限，写入策略带取值范围校验（分数 0~100、各项计数 0~40、
  违规码限定在 `leave / screenshot / split / copy / sound` 白名单内），**任何人都无法直接读取成绩表**。
- 教师端口令门、读取、删除分别走服务端函数 `teacher_login(p_key)` / `teacher_exam_records(p_key)` /
  `teacher_delete_record(p_key, p_id)`；三者都是 `SECURITY DEFINER`，在 SQL 内部校验口令，
  后两者复用 `teacher_login` 判定身份。**口令只写在服务端函数里，前端代码不含任何口令**。
- 前端只携带 `publicConfig` 中的 `endpoint` / `oauthRelayBaseUrl` / `publishableKey`。

> ⚠️ 为便于部署，`assets/workbuddy-cloud-sdk.js` 是云服务 SDK 的自带副本
> （`@tencent-ai/workbuddy-cloud-sdk@0.1.3-dev.05a12d5`，npm `dev` 通道的 IIFE 构建），
> 页面运行时不依赖任何外部 CDN。

## 运行方式

**方式一：线上使用**（推荐，成绩可汇总）

学生打开站点答题，教师打开 `teacher.html` 查看汇总。
云服务按发布域名做 Origin 校验，因此**必须通过发布域名访问**才能写入云端。

**方式二：本地运行**

```bash
python -m http.server 8080
# 浏览器访问 http://localhost:8080
```

本地运行时会因 Origin 不匹配而无法写入云端，但**答题、判分、倒计时、考场管控、错题回溯、成绩单下载全部照常可用**。

## 题库更新方式

**选择题库**（三份 docx）：

```bash
python tools/build_banks.py 军事题库.docx 学生手册题库.docx 安全知识题库.docx
```

`build_banks.py` 处理了真实题库的排版问题：选项与题号粘连（`D.10` + `59.` → `D.1059.`）、
小数选项粘连（`D.1.8` + `75.` → `D.1.875.`）、答案标记写在题干中间、小节标题混入选项末尾等。

**填空题库**（`自编题(1).doc`）：

```bash
python tools/extract_doc.py 自编题.docx tools/parsed/zibian.txt   # 需要时先看原文
python tools/build_fill_bank.py
```

- 原文档把**填空答案用加粗标出**，`build_fill_bank.py` 里逐题记录了题干、空格答案与判分接受写法，
  修改后重新运行即可生成 `assets/banks_fill.js`。
- `tools/extract_doc.py` 直接解析 Word 97-2003 二进制格式（OLE2 + 分片表），只依赖 `olefile`。
  注意 `.doc` 的 `fcMin/fcMac` 是失效的遗留字段，正文必须以分片表为准。

## 运维备注

- **口令轮换**：四个教师口令都定义在服务端函数 `teacher_login` 的 VALUES 列表里，
  单独替换其中任意一个只影响该教师、其余三人不受影响，旧口令立即失效。
- **口令分发**：建议每位教师只持有自己的口令，离岗或轮换时单独作废，便于追责。
- **判分在前端完成**：云端只保存考生上报的结果，不做二次判分；写入策略会校验取值范围拦截明显异常的数据。
- **违规申诉**：违规判定含启发式规则（如分屏比例、声音阈值），教师端提供违规详情与发生时间，
  建议对疑似误报的记录人工复核后再处理。
- 表内数据可用教师端看板逐条删除，或在云服务控制台按需清理。
